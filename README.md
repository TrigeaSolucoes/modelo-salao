# Studio Íris Beleza — site-modelo

Site-modelo **fictício** de Salão de beleza e estética em Ipatinga (MG), criado pela [Trígea Soluções](https://trigea.com.br/) para mostrar como pode ficar o site de um negócio desse ramo.
Negócio, pessoas, telefones e endereços são inventados.

Demonstração: https://trigeasolucoes.github.io/modelo-salao/

Quer um site assim para o seu negócio? Fale com a Trígea: https://trigea.com.br/
